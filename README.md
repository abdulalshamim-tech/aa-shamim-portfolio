ABDUL ALL SHAMIM — Portfolio Website
====================================

Static HTML/CSS/JavaScript website. No paid hosting, domain, database, or build step is required.

FILES
- index.html
- style.css
- script.js
- assets/

LOCAL PREVIEW
Open index.html in a browser.

FREE DEPLOYMENT TO CLOUDFLARE PAGES
1. Extract this ZIP.
2. Create/sign in to a Cloudflare account.
3. Open Workers & Pages -> Create -> Pages -> Upload assets (Direct Upload).
4. Upload the extracted project folder (the folder containing index.html and assets).
5. Choose a project name such as shamim.
6. Deploy. Cloudflare will provide a *.pages.dev address.
7. To use an existing Pages project, upload a new deployment to that project instead.

EDITING
- Update text and links in index.html.
- Replace images inside assets/ using the same filenames, or update the image paths in index.html.
- Client Reviews section is intentionally left empty; no fabricated reviews are included.
- The two website screenshots are shown as project previews. Add live project links only after confirming their URLs.
- Experience is shown as 3+ years based on the information supplied; edit if needed.

NOTE
The website is a static portfolio. A working contact form would require a third-party form service or backend. Email and phone links are provided instead.
